# thai-vocab-site

Public pages for the Dailyvokab iPhone app: the home page, the support page and the privacy policy.

- https://adamvasica.github.io/thai-vocab-site/
- https://adamvasica.github.io/thai-vocab-site/support.html
- https://adamvasica.github.io/thai-vocab-site/privacy.html

The source of these pages is `site/` in the app repo. Edit them there, run `node scripts/test-privacy-policy.mjs` and `node scripts/test-site-pages.mjs`, then copy them here.
